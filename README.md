# Task Manager

A small C++ project for learning and practicing modern C++.

## Features

* Create tasks
* Store tasks in `std::vector`
* Find tasks by ID
* Remove tasks by ID
* Change task status
* Change task priority
* Display all tasks
* Automatically generate task IDs

## Technologies

* C++20
* STL
* CMake
* Visual Studio
* Git
